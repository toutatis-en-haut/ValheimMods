# Extended Storage

Tabbed storage cabinets for Valheim. One footprint, six labelled drawers,
fewer entities in your base.

## Cabinets in v0.1

- **Wooden Cabinet** — 6 drawers × 15 slots (90 total). 100 wood + 20 resin
  at workbench level 3. Built with the hammer; placed on a floor piece or
  flat ground.

## Features

- 6 named tabs per cabinet, each holding 15 items.
- Tab labels: up to 25 characters, default `1`–`6`, edited in place.
- Tab strip wraps to a second row when labels are long, matching the build
  hammer's category bar.
- Per-tab fill indicator (`N/15`).
- **Shift-hover** a cabinet to see all six tab contents at a glance, without
  opening it.
- Quick switch tabs with the **1**–**6** keys; mouse wheel scrolls content.
- Stagger-drops items on destruction to avoid frame spikes.
- Respects warded (PrivateArea) access like vanilla chests.

## Dependencies

- BepInEx 5.4.21+ (5.4.23.3 recommended)
- ValheimModding-Jotunn 2.29.0+
